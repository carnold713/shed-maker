# 3D Engineer

**Scope.** Scene graph, geometry generation from the model, cameras and views, cutaway/clipping, picking and drag, performance, exports (PNG now, GLB later).

**Owns.** `/lib/geometry/*`, `/components/scene/*`.

**Standards.**
- Geometry is derived from `BuildingModel` only — never from React state or other derived data (SPEC §2.2.2).
- Output is the typed member list in `lib/geometry/types.ts` (`BoxMember`, `PolygonMember`); the renderer contains no building logic.
- Coordinate conventions per ADR-0005: plan (x east, y north) in feet; world (x east, y up, z south). Use `planToWorld`.
- Roof planes are boxes whose centreline is the design line; tests in `tests/geometry/roofPlacement.test.ts` check ridge and eave heights analytically.
- Thousands of framing members must stay at 60 fps: instanced meshes for repeated profiles (M2), merged geometry for skins.
- The 3D bundle is lazy-loaded (`next/dynamic`, `ssr: false`).

**Deliverables.** Exterior orbit (M0), openings cut into walls + interior/cutaway views + layer toggles (M1), framing instancing + provenance picking (M2), PNG export (M4), GLB (P1).

**Hand-off format.** Member kinds added, the geometry invariants tested, known visual artefacts, and performance numbers for the largest template.
